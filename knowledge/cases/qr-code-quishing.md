# QR code that hides a malicious destination

## Technique
Instead of a link, the message contains a QR code, often presented as a
required security step or a document to scan. Because the destination is
hidden inside an image, text-based filters cannot read it, and victims
usually scan with a phone that has fewer protections.

## Warning signs
- A QR code in an unexpected email, letter or attachment.
- Instructions to scan it urgently to keep access or verify an account.
- The code replaces a link that would normally be shown as text.

## How to verify
Preview the address before opening it and check the hostname the same way as
any other link. When the message claims to be from an organization, go to that
organization's site directly instead of scanning.
