# Shortened or tracking link hiding the real destination

## Technique
The message uses a link-shortening service or a long tracking URL, so the real
hostname cannot be seen before clicking. The destination is a credential page
or a download.

## Warning signs
- A shortened link in a message that claims to come from a bank or service.
- A shortened link where the organization normally uses its own domain.
- No other context about where the link leads.

## How to verify
Use a link preview or expander to see the final destination without visiting
it, then check the hostname as with any other link. If the message claims to
be from an organization, open its site directly instead.
