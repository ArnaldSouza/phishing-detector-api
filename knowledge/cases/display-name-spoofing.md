# Sender display name that does not match the real address

## Technique
The visible sender name shows a trusted person or company, but the underlying
address belongs to an unrelated or free mail account. Many mail clients,
especially on phones, show only the name and hide the address.

## Warning signs
- A known name sent from a free mail provider or an unfamiliar domain.
- A reply-to address different from the sender address.
- An address that imitates the real one with small spelling changes.

## How to verify
Expand the sender details and read the full address. Compare the domain with
the one the organization actually uses.
