# Request to share a one-time verification code

## Technique
The attacker is already logging in to the victim's account and needs the
one-time code sent by the real service. The message, call or text claims to be
support, a delivery service or a friend, and asks the victim to read the code
back.

## Warning signs
- A code arrives that you did not request, followed by a message asking for it.
- The requester gives a reason why the code is needed, such as "to cancel a
  fraudulent login".
- Pressure to share the code quickly.

## How to verify
Never share a one-time code with anyone. A legitimate service does not ask for
it. An unexpected code means someone is trying to enter the account, so change
the password.
